Dynamic Programming Visualization Handbook

Sourabh Bose · 2026

This handbook connects recursive programs, state graphs, and dynamic programming tables through small, fully worked examples. It assumes familiarity with Python, recursion, and basic graph algorithms.

Seven chapters cover Fibonacci, 0/1 knapsack, edit distance, water jugs, matrix-chain multiplication, Tower of Hanoi, and Two Sets II. Diagrams trace calls and returns, show how repeated subproblems form dependency graphs, and connect those dependencies to table evaluation. The cyclic examples distinguish path-local cycle rejection from shortest-path computation.
